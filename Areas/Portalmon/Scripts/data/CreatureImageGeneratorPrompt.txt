Portalmon Sprite Generation Prompt

  Style Reference (use this preamble for every creature)

  Generate a single creature sprite in the style of a Game Boy Advance-era
  Pokemon sprite (Pokemon Ruby/Sapphire/Emerald generation). The art style
  should be:

  - Clean pixel art, roughly 96x96 pixels
  - Sprite-sheet framing rule: bottom-aligned. The creature’s lowest pixel touches the bottom edge of the canvas (y=95). Crop/position so there are 0–1 px of empty space below the feet/body. Any extra padding must be only above the head, not below.
  - 3/4 front view with rightward yaw: classic Pokemon encounter angle — facing toward the viewer, turned ~10–20° toward screen-right with a clear face direction
  - Limited but vibrant color palette (12-16 colors max per creature, with
    clear shading — a base color, a highlight, and a shadow tone per region)
  - Transparent background (PNG with alpha). No ground, no shadow, no effects.
  - Black or very dark outline (1px), with the creature fully self-contained
    within the frame
  - The creature should look like a cute/cool fictional monster that could
    plausibly exist in a Pokemon game — expressive eyes, simple but readable
    silhouette, and a clear "face" direction
  - The creature's design should visually hint at its IT infrastructure theme
    without being too literal — think "what if a Pokemon was inspired by [concept]"
    not "a cartoon drawing of [concept]"
  - If there is visible empty space under the creature, the image is incorrect.

  DO NOT include: text, labels, names, UI elements, multiple angles,
  background scenery, drop shadows, glow effects, or excess bottom padding under the creature when grounded.
